# 家庭成员与媒体迁移

在独立环境验证后再上线。执行数据库迁移前，备份数据库并确认管理员仍可登录。迁移保留现有管理员权限，普通旧账号进入待确认状态。管理员在「个人中心 → 家庭成员」开通家人账号或生成一次性邀请码。

## 历史图片

1. 为应用连接一个私有 Vercel Blob 存储，配置服务端变量 `BLOB_PRIVATE_READ_WRITE_TOKEN`。将原公开 Blob 存储的完整 HTTPS origin 配置为 `BLOB_LEGACY_PUBLIC_ORIGIN`。
2. 在迁移环境运行 `node scripts/migrate-family-media.mjs --inventory`，核对照片、旅行封面及图片、头像和生日缩略图。脚本会单列来自其他存储和相对路径的引用。
3. 确认旧文件与数据库可恢复后，运行 `node scripts/migrate-family-media.mjs --copy-images`。脚本校验私有副本的大小和哈希后替换数据库引用，保留复制失败或并发被修改的引用，方便重试。
4. 核对剩余历史引用并验证家人可以正常加载。清理旧公开对象前，核对存储中无其他使用方。清理后在无登录会话下验证旧地址已失效。脚本只复制与切换数据库引用，旧对象需要独立清理。

## 生日影像

检查哔哩哔哩创作后台中的原视频可见性。拿到家庭留存的 MP4 原文件后，运行 `node scripts/migrate-family-media.mjs --attach-video <记录ID> <MP4路径>`，保留原记录的年份、标题和说明。确认已登录家人可以播放和拖动进度条，未登录访问播放地址得到 401。再按家庭意愿调整站外原视频的可见性并从未登录会话复核。未迁移的影像沿用哔哩哔哩播放。
